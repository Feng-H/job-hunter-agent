# Job-Hunter 智能求职采集助手（Chrome 浏览器扩展）

专为 Job-Hunter OS 打造的轻量、零风控、突破 CSP 的求职数据采集插件。

## ✨ 核心特性
1. **常驻右上角**：突破 Chrome 书签栏自动隐藏问题，随时随地一键使用；
2. **突破 CSP 拦截**：在任何严格 CSP 限制的招聘网站上畅通无阻运行；
3. **智能悬浮胶囊**：在浏览 Boss直聘、猎聘、智联职位搜索列表时，右下角自动弹出「🎯 发现 N 个岗位 | 点击同步」小胶囊，支持翻页无感采集；
4. **两段式采集（无需逐个进详情页）**：
   - **列表页（快）**：卡片自带公司名/薪资/城市/标签，一键批量同步即可完成快速初筛；
   - **详情页（深）**：对过筛岗位打开详情页，胶囊自动切换为绿色「🔬 深度抓取全量 JD」，点击即抓取完整职位描述送入 AI 深度分析；
5. **猎头帖自动识别**：猎聘上猎头代发帖（含"某知名企业"类模糊代称）自动打上「猎头帖」标记，云端通过职位指纹与官方直发帖自动关联溯源真实企业；
6. **完全 0 封号风险**：纯前端 DOM 解析，走用户正常浏览请求，招聘软件完全感知不到任何爬虫行为。

## 🚀 10 秒快速安装指南
1. 打开 Google Chrome 或 Edge 浏览器，地址栏输入：
   `chrome://extensions/`
2. 开启右上角的 **「开发者模式」(Developer Mode)** 开关；
3. 点击左上角的 **「加载已解压的扩展程序」(Load unpacked)**；
4. 选择本项目根目录下的 **`extension`** 文件夹即可完成安装！
5. 点击浏览器右上角拼图图标，将 **「Job-Hunter 采集助手」** 图标固定在工具栏；
6. 点击该图标，填入你的 Job-Hunter 看板地址（如 Vercel 域名）和在 `/setup` 页获取的专属采集令牌，点击保存即可！
